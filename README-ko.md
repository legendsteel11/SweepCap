# SweepCap

[English](README.md)

단축키를 누른 채 드래그하면 그 자리에서 캡처가 끝나는 Windows 캡처 유틸리티입니다.
키를 누르고, 도구가 뜨기를 기다리고, 영역을 선택하는 단계가 없습니다.
드래그가 곧 캡처입니다.

## 다운로드

[릴리즈 페이지](https://github.com/legendsteel11/SweepCap/releases/latest)에서 최신
버전을 받으세요. 파일은 `SweepCap.exe` 하나입니다.

- 설치가 없습니다. 원하는 곳에 두고 실행하면 트레이에 상주합니다.
- 별도 런타임 설치가 필요 없습니다.
- 관리자 권한을 요구하지 않습니다.
- Windows 11 이상에서 동작합니다.

## 사용법

기본 단축키는 `Ctrl+Win`이고, 트레이 메뉴에서 변경할 수 있습니다.

| 조작 | 동작 |
|---|---|
| `Ctrl+Win` + 드래그 | 영역 캡처 |
| `Ctrl+Win` + 클릭 | 커서 아래 창 캡처 |
| `Ctrl+Win` + 바탕화면 클릭 | 그 모니터 전체 캡처 |
| 드래그 중 `Shift` | 선택 영역을 격자에 스냅 |
| 우클릭, `ESC` | 취소 |
| 창 크기 조절 중 `Ctrl+Win` | 놓는 순간 창 크기를 격자에 스냅 |

캡처는 클립보드와 PNG 파일로 동시에 저장됩니다. 파일은
`사진\SweepCap\<날짜>\` 아래에 `앱이름_날짜_시각.png` 형식으로 쌓이고, 트레이
아이콘을 더블클릭하면 그 폴더가 열립니다. 어느 앱을 찍었는지가 파일명에
남으므로 나중에 찾기 쉽습니다.

## 트레이 메뉴

모든 설정은 트레이 아이콘 우클릭 메뉴에 있습니다.

- **캡처 폴더 열기**: 캡처 파일이 저장된 폴더를 엽니다.
- **단축키 변경**: 원하는 단축키 조합을 선택합니다. RDP 환경에서는 `Win`키가
  없는 조합을 사용할 수 있습니다.
- **캡처 격자**: 격자에 맞추는 캡처의 격자 간격을 선택합니다.
- **창 격자**: 창 크기를 격자에 맞출 때의 격자 간격을 선택합니다.
- **바깥 어둡게**: 영역을 선택하는 동안 선택 밖 화면의 밝기를 선택합니다.
- **저장 폴더**: 캡처가 저장될 폴더를 변경합니다. 날짜 폴더 없이 한 폴더에
  모으는 옵션도 여기 있습니다.
- **부팅 시 시작**: Windows 시작 시 자동으로 실행됩니다.
- **앱 정보**: 버전과 제작자 정보를 표시합니다.
- **다시 시작**: 앱을 다시 시작합니다.
- **종료**: 앱을 종료합니다.

## 왜 이렇게 만들었나

기존 캡처 도구는 "키를 누른다, 도구가 뜬다, 영역을 선택한다"의 순서를
거칩니다. 키보드 단축키 체계가 마우스를 볼 수 없어서 키 입력과 드래그가
분리되고, 그래서 모드가 생깁니다.

SweepCap은 마우스 입력을 직접 받아 이 분리를 없앴습니다. 단축키를 누른 채
버튼을 누르는 순간 화면이 정지 화면으로 고정되고, 잘라내기는 그 정지 화면에서
합니다. 그래서 빠르고, 선택 UI가 결과물에 찍히는 일이 없습니다.

## 기능

- 영역, 창, 모니터 전체 캡처를 제스처 하나로 구분합니다. 드래그면 영역,
  클릭이면 창입니다.
- 창 캡처는 Windows 11의 둥근 모서리를 투명하게 살립니다.
- 격자 스냅을 캡처와 창 크기 조절 양쪽에 지원합니다. 격자 간격은 픽셀과
  화면 분할 중에서 선택합니다.
- 클립보드에는 PNG와 DIBV5를 함께 올려, 붙여넣는 앱에 따라 알파가 깨지는
  문제를 피합니다.
- 다중 모니터와 모니터별 배율(Per-Monitor V2 DPI)을 지원합니다.
- UI는 한국어와 영어를 제공하며 Windows 표시 언어를 따릅니다.
- 설정은 전부 트레이 우클릭 메뉴에 있습니다. 단축키, 격자, 저장 폴더,
  날짜 폴더 사용 여부, 부팅 시 시작을 변경할 수 있습니다.

## 빌드

Visual Studio 2022(C++ 데스크톱 워크로드)와 Windows 11 SDK가 필요합니다.
외부 패키지 의존성이 없어 저장소만 받으면 빌드됩니다.

```
build.bat release
```

결과물은 `build\release\SweepCap.exe`입니다.
